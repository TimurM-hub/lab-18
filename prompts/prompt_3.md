## 🧮 Логика функций

**`sumDigits` (рекурсивная):**
- Базовый случай: если `n == 0` → возвращаем 0 (сумма цифр нуля равна 0).
- Рекурсивный шаг: последняя цифра = `n % 10`, остаток = `n / 10`. Сумма = `последняя цифра + sumDigits(остаток)`.
- Отрицательные числа: берём модуль (`abs`), чтобы знак не мешал.

**`isDivisibleBy3`:**
- Просто проверяем `n % 3 == 0`. Работает и для отрицательных чисел.

## 1. Заголовочный файл `math_utils.h`

```cpp
#ifndef MATH_UTILS_H
#define MATH_UTILS_H

// Рекурсивная функция вычисления суммы цифр числа.
// Корректно обрабатывает 0 и отрицательные числа.
// Пример: sumDigits(123) = 6, sumDigits(-456) = 15, sumDigits(0) = 0.
int sumDigits(int n);

// Функция проверки делимости числа на 3.
// Возвращает true, если число делится на 3 без остатка.
bool isDivisibleBy3(int n);

#endif // MATH_UTILS_H
```

## 2. Файл реализации `math_utils.cpp`

```cpp
#include "math_utils.h"
#include <cmath>   // для std::abs

// Рекурсивная сумма цифр
int sumDigits(int n) {
    // Берём модуль числа, чтобы корректно работать с отрицательными
    n = std::abs(n);

    // Базовый случай рекурсии: число стало 0 — больше цифр нет
    if (n == 0) {
        return 0;
    }

    // Рекурсивный шаг:
    // n % 10 — последняя цифра
    // n / 10 — число без последней цифры
    return (n % 10) + sumDigits(n / 10);
}

// Проверка делимости на 3
bool isDivisibleBy3(int n) {
    return (n % 3) == 0;
}
```

> 💡 **Важный нюанс про `INT_MIN`**: если передать `-2147483648` (минимальное значение `int`), то `std::abs` даст переполнение, потому что `+2147483648` не влезает в `int`. Для лабы это обычно не требуют, но если хочешь «пуленепробиваемый» вариант — замени параметр на `long long`.

```cpp
    std::cout << "sumDigits(-456)  = " << sumDigits(-456)  << "  (ожидается 15)\n";

    int testNums[] = {0, 3, 5, -9, 10, 123, 100};
    for (int num : testNums) {
        std::cout << num << " делится на 3? "
                  << (isDivisibleBy3(num) ? "ДА" : "НЕТ") << "\n";
    }

    return 0;
}
```
